# Isometric Diorama Studio

Dans Codex ou Claude Code, demander une scène miniature isométrique, puis indiquer le décor, les acteurs, leurs gestes et la destination du film. Le plugin fournit six skills, deux connecteurs MCP et des commandes locales pour créer, importer, inspecter, rendre et encoder. Il inclut un bureau Blender éditable et un poisson de bibliothèque pour essayer le parcours sans génération payante.

[Installer les connecteurs](docs/connexion.md) · [Commencer l’exercice](docs/atelier.md) · [Retrouver les sources](docs/sources.md) · [Voir le film d’origine](https://github.com/ohvignas/isometric-diorama-studio/tree/main/showcase)

Dans Claude Code récent, installer en une commande.

```text
/plugin install isometric-diorama-studio --marketplace ohvignas/isometric-diorama-studio
```

La [scène Blender de production](https://github.com/ohvignas/isometric-diorama-studio/releases/download/v1.1.0/Coworking-Illith-source.blend) contient le coworking complet avec les trois personnages. La [visite illustrée](https://github.com/ohvignas/isometric-diorama-studio/tree/main/showcase/scene) donne les images à explorer.
