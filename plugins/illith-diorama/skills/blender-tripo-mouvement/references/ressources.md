# Tutoriels, forums et outils

| Pour travailler sur… | Où regarder et quoi en tirer |
| --- | --- |
| Un humain Tripo P2.0 | Le tutoriel officiel suit un personnage depuis le maillage jusqu’aux UV, matériaux, squelette et export. La documentation du module précise le rôle de l’auto-rig. Vérifier l’alignement et les poids aux articulations en pose. [Parcours Smart Mesh P2.0](https://www.tripo3d.ai/tutorials/mesh-game-character-p-2) · [Rigging & Animation](https://www.tripo3d.ai/product-doc/module-post-processing/rigging-animation) |
| Récupérer le personnage dans Blender | Le DCC Bridge transfère un modèle et les animations sélectionnées de Studio. Tripo indique un compte Studio Pro, Max ou Team pour cette intégration. Le FBX ou GLB déjà exporté se réimporte localement. Le module de génération via l’API est une intégration distincte. [DCC Bridge pour Blender](https://www.tripo3d.ai/integrations/blender) · [Extension API officielle](https://github.com/Tripo-Developer/tripo-3d-for-blender) |
| Adapter une animation à un autre squelette | Rokoko explique le choix des deux armatures, la liste de correspondance, les poses de référence et Auto Scale. Le transfert d’une animation importée est gratuit selon l’éditeur. En présence de pieds enterrés, comparer la pose courante et la pose de repos et refaire l’essai d’échelle sur une copie. [Tutoriel de transfert](https://support.rokoko.com/hc/en-us/articles/4410463481489-Retarget-an-animation-in-Blender) · [Versions de l’extension](https://github.com/Rokoko/rokoko-studio-live-blender/releases) |
| Trouver une prestation de départ | Mixamo permet de rechercher et prévisualiser une action sur un personnage. Inspecter l’entrée, la sortie et la présence de mouvement de racine. Le donneur effectivement utilisé pour la marche Illith est Xbot. [Guide Adobe](https://helpx.adobe.com/creative-cloud/help/animate-characters-mixamo.html) · [Modèle Xbot du dépôt three.js](https://github.com/mrdoob/three.js/blob/dev/examples/models/gltf/Xbot.glb) |
| Étudier le poids et les poses | « Walking Vanilla » et « Weight Shift » donnent une progression pédagogique. Le sommaire est public et les leçons complètes de Blender Studio nécessitent un abonnement. L’exercice gratuit de Player Motion détaille les contacts opposés et le bouclage. Pierrick Picaut présente aussi un cycle en vidéo. [Blender Studio](https://studio.blender.org/training/animation-fundamentals/) · [Exercice guidé sur les contacts](https://playermotion.games/lessons/blender-animation/pose-walk-contacts) · [Tutoriel de Pierrick Picaut](https://www.youtube.com/watch?v=SLh3hUIxv1s) |
| Diagnostiquer un pied qui patine | Sur Blender Artists, les animateurs détaillent une fixation temporaire du contrôleur à un Empty monde et le bake des clés visuelles. Un deuxième fil illustre le cas difficile d’une action alternant arrêt et déplacement. Rejouer le transfert talon–pointe après chaque verrouillage. [Fil sur le pied qui glisse](https://blenderartists.org/t/fix-sliding-feet-in-blender/1620939) · [Cas d’une capture avec arrêt](https://blenderartists.org/t/correcting-slipping-feet-in-a-mocap-animation/1451786) · [Manuel IK Blender](https://docs.blender.org/manual/en/latest/animation/constraints/tracking/ik_solver.html) |
| Examiner un outil de nettoyage supplémentaire | L’auteur de Foot Flow présente un module de nettoyage des tremblements, de contact et de verrouillage des pieds. Consulter la compatibilité de la version offerte et essayer sur une copie avec le même test avant/après. Outil repéré sur le forum, non évalué dans la scène Illith. [Présentation de Foot Flow par son auteur](https://blenderartists.org/t/foot-flow-new-foot-animation-cleanup-add-on/1640052) |
| Étudier un salut ou un lever réel | Le catalogue Carnegie Mellon et ses fichiers C3D donnent les trajectoires et la fréquence de capture. Le cas Illith documente les extraits locaux. Vérifier les conditions applicables à la diffusion du fichier source. [CMU sujet 141](https://mocap.cs.cmu.edu/search.php?subjectnumber=141) · [CMU sujet 13](https://mocap.cs.cmu.edu/search.php?subjectnumber=13) · [FAQ du laboratoire](https://mocap.cs.cmu.edu/faqs.php) |
| Saisir une tasse ou une poignée | Pour une tasse libre, la main conduit la tasse pendant la prise. Pour une poignée à pivot fixe, l’objet conduit le point d’appui de la main. Placer un repère à l’endroit où touchent les doigts et vérifier la transformation visuelle aux images de prise et de lâcher. Le fil Blender Artists détaille cette transition. PropHandoff est aussi référencé pour attacher un accessoire et le passer entre deux mains ; extension documentée, à tester sur une copie. [Exemple pratique sur Blender Artists](https://blenderartists.org/t/attaching-detaching-objects/606830) · [Fiche de PropHandoff](https://extensions.blender.org/add-ons/prop-handoff/) |
