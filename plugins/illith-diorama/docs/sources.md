# Carnet des sources

113 adresses issues des notes de fabrication et de la documentation d’installation. Les ressources utilisées à l’image sont identifiées dans [les crédits du film](credits.md). Les autres liens servent de tutoriels, de documentation ou de pistes étudiées. Les prix, versions et droits applicables sont ceux indiqués par chaque éditeur.
